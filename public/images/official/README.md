# Fotografias oficiais do Instagram

As 23 imagens desta pasta foram importadas em 15/10/2026 a partir de publicações públicas do perfil oficial `@studiosuelenvaes`, conforme solicitação do responsável por este projeto. A origem de cada arquivo está registrada em `data/media-sources.json`.

Formato recomendado: WebP, qualidade 82–88, perfil sRGB. Hero em 2400×1600 px; retratos em 1600×2000 px; galeria com lado maior entre 1600 e 2200 px. Nunca ampliar uma imagem pequena.
